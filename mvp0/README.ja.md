# New8bitPC Windows MVP 1-A / 1-B / 1-C

この隔離されたプロトタイプは、入力した各ページのソース文字列を変更せずに保持し、確定済みページから行解析結果と実行可能な命令を生成します。

現在対応しているのは、文字列リテラル形式の `PRINT`、数値行番号への `GOTO`、no-opとして通過する `REM`、実行を終了する `END`、数値変数と式による代入です。代入は`LET A=式`または`A=式`で行います。その他の命令は「未解釈」として報告され、実行時にスキップされます。完全なN88-BASICエミュレーターではありません。

式評価は数値リテラル、単項マイナス、括弧、四則演算、比較演算（`=`, `<>`, `<`, `<=`, `>`, `>=`）に対応します。変数名は英字で始まり、大文字小文字を区別しません。比較の成立は`-1`、不成立は`0`です。0除算と未定義変数の参照は実行エラー、式の書式不正は誤りとして扱います。`IF 式 THEN 行番号`に対応します。真なら指定行へジャンプし、偽なら次行へ進みます。未解決のジャンプ先はGOTOと同様に参照待ち／完成時の誤りとして扱います。`INPUT`、`FOR...NEXT`、`GOSUB...RETURN`、`RND`、`INT`、`CLS`、`PRINT`の式評価、THEN句の命令、`ELSE`、コロン区切りは対象外です。

`10PRINT"A"` や `10GOTO100` のようなコンパクトな形式は、命令と引数の境界が明確な場合に受け付けられます。一方、`10PRINTA` のような曖昧な形式は未解釈のままです。これらはMVP独自の入力ルールであり、N88-BASIC実機環境の仕様を示すものではありません。

## 実行方法

Node.js 20以降をインストールし、このディレクトリで次のコマンドを実行します。

```powershell
node server.mjs
```

ブラウザーで <http://127.0.0.1:4173> を開いてください。初期状態では、次ページエディターに動作確認用の2行サンプルが入力されています。**区切り**を押すと、そのページを確定して解析します。別のページを入力して確定すると、ページをまたいだ参照が解決されます。**完成**を押すと、残っている入力を確定し、未解決のジャンプ先を持つ行を誤りとして扱います。ソースを入力または修正すると、解析状態は未完了に戻ります。

## Rawの保持と再解析

確定済みのソースページは別途表示され、解析や実行によって書き換えられません。確定済みページを展開して**このRawを編集**を選ぶと、エディターに読み込めます。**このページを更新して再解析**を実行すると、そのページを置き換え、Rawを基準に解析を再構築します。前のページを編集中でも、次ページに入力中の文字列は保持されます。解析済み行の**訂正**は、1行だけ修正するために使用できます。

## 訂正履歴

訂正履歴には、タイムスタンプ、ページ番号、ページ内の行番号、変更前後の行文字列、変更元（`human`または`ai(承認つき)`）が記録されます。履歴はRawとは別に保持されます。初回入力は訂正履歴に追加されません。

複数行のページ編集では、変更されていない行を照合します。そのため、行の挿入・削除によって後続の変更されていない行が誤って編集済みとして記録されることはありません。追加または削除された行は、変更前または変更後の値が空になります。

## 保存とJSON入出力

プロジェクトは、このブラウザーのIndexedDBに自動保存されます。**JSONを書き出す**と**JSONを読み込む**を使うと、持ち運び可能なUTF-8形式のプロジェクトファイルを作成・読み込みできます。

JSONには`formatVersion`、Rawページ文字列、保留中の入力、完了状態、訂正履歴が保存されます。解析結果や行数・枠線色などの表示専用値は保存されず、再計算されます。インポート時には形式バージョンを確認し、現在のプロジェクトを置き換える前に確認を求めます。

## ストレージについて

ブラウザーのストレージは、ポートを含むページのオリジンごとに分離されています。通常のサーバーURLはポート`4173`を使用します。ポートを変更すると別のブラウザーストレージ領域が使われます。ポート変更前にJSONを書き出し、新しいURLで読み込んでください。元に戻す／やり直す機能はありません。

## 出力と実行ログ

モニターには`PRINT`によるプログラム出力のみが表示されます。実行ログには、実行時に通過した行、ステップ番号、スキップされた理由が記録されます。`REM`はno-opとして、`END`は実行終了命令としてログに表示されます。

## 実行時の停止判定（暫定MVP設定）

最低10ステップの判定対象が蓄積した後、判定対象となる直近20ステップのうち半数以上がスキップされると、実行を一時停止します。また、`PRINT`出力がない状態が500ステップ連続した場合も一時停止します。未解決の参照は、**完成**を押すまでスキップ率の計算対象から除外されます。

**続ける**を選ぶと、次回確認までの間隔が2倍になります。スキップ率の再確認間隔は最大160ステップ、出力なし判定の再確認間隔は最大4000ステップです。上限に達した場合、その実行中に限り、該当理由による確認を抑制できます。Workerの実行中も**停止**を利用できます。

## 入力プロファイルへの注意

**区切り**を押した際、ページに5行以上あり、未解釈行が過半数を占める場合は、入力を妨げない通知が表示されます。また、行数にかかわらず全行が未解釈の場合も通知対象です。プロファイルの不一致を断定するものではなく、入力傾向に対する参考情報です。しきい値や判定ルールは暫定的であり、対応命令の追加に伴って変更される可能性があります。

## 手動確認項目

1. **デフォルトサンプル** — **区切り**を押して実行します。`HELLO`が繰り返し表示され、ステップ数が増えることを確認します。**停止**を押し、カウントが止まり、ほかの操作が利用できることを確認します。
2. **未解釈行** — 別ページに`30 FOO`を入力して**区切り**を押します。ページ内の未解釈行が1件と報告され、実行ログでスキップされたことを確認します。
3. **参照待ちと誤り** — ページに`10 GOTO 100`を入力して確定し、**参照待ち**になることを確認します。別ページに`100 PRINT "FOUND"`を入力して確定し、参照が解決されることを確認します。未解決のまま**完成**を押した場合は**誤り**になることを確認します。
4. **行番号順実行** — 1ページに次の2行を入力します。Rawの並び順が維持され、実行はBASIC行番号順に始まることを確認します。

   ```basic
   20 GOTO 10
   10 PRINT "HELLO"
   ```

5. **重複行番号** — 同じ行番号10を持つ命令を2つ入力します。解析結果に両方のソース位置が表示され、実行ログに**重複のため実行対象外**と表示されることを確認します。
6. **コンパクト構文とRaw再編集** — `10PRINT"A"`と`10GOTO100`は解釈され、`10PRINTA`は未解釈になることを確認します。次に確定済みページのRawを編集して更新し、ページ番号が維持されること、解析結果が更新されること、保留中の次ページ入力が保持されること、変更行が訂正履歴に記録されることを確認します。
7. **未解釈率の注意** — 未解釈行が過半数を占める5行以上のページを確定し、入力を妨げずに通知されることを確認します。また、全行が未解釈のページでは、5行未満でも通知されることを確認します。
8. **REMとEND** — 次のプログラムを実行し、Rawコメントが保持され、REMがno-opのステップとして記録され、`HELLO`が出力されることを確認します。

   ```basic
   10 REM COMMENT
   20 PRINT "HELLO"
   ```

   続いて次のプログラムを実行し、`BEFORE`のみが出力され、`AFTER`は実行されず、END到達時に実行が終了することを確認します。

   ```basic
   10 PRINT "BEFORE"
   20 END
   30 PRINT "AFTER"
   ```

9. **変数・式・代入** — 次の代入を実行し、変数の値が`A=-5`、`B=17`、`C=-1`になることを確認します。

   ```basic
   10 LET A=-5
   20 B=(A*-2)+(10-3)
   30 C=B>=10
   ```

   続いて`LET D=B/0`と`LET E=UNKNOWN+1`を実行し、それぞれ0除算と未定義変数の実行エラーになることを確認します。

10. `10 A=1`、`20 IF A=1 THEN 100`、`30 PRINT "NG"`、`40 END`、`100 PRINT "OK"`、`110 END`を実行します。真なら100行へジャンプし、偽なら次行へ進むことを確認します。未解決のジャンプ先は未完成時に参照待ち、完成時に誤りになることを確認します。
